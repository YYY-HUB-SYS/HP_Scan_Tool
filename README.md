# 🖨️ HP Scan Tool



惠普集成扫描工具（HP Integrated Scan Tool）是一款面向惠普网络打印机的 Windows 桌面扫描客户端。通过 eSCL/AirScan 协议实现免驱网络扫描，WIA 作为本地 USB 降级方案，WS-Discovery 作为补充发现协议。

## 功能特性

- 🚀 **免驱扫描**：eSCL/AirScan 纯 HTTP/XML 协议，无需安装厂商驱动
- 🔍 **双协议发现**：mDNS + WS-Discovery 并行发现局域网扫描仪
- 📄 **多页扫描**：支持平板单页和 ADF 自动多页扫描
- 🔁 **手动双面**：正面一趟 + 翻面背面一趟，合并后正反页交错成一份文档
- 🧩 **断点续扫**：扫描被打断后可从第 N 页继续，前面的页保留
- 📚 **大批量合并**：多批扫描合并成**一个** PDF（或按页导出图片）
- 📐 **自动纠偏**：每页自动测倾斜角，落盘时按阈值摆正；连续歪斜会弹强提醒
- 💾 **磁盘缓存**：扫描数据先落盘，预览后确认保存，避免内存占用
- 📝 **历史记录**：自动记录扫描历史，支持浏览和清空
- 💻 **CLI 模式**：支持命令行批量扫描/发现/状态查询
- 📦 **单文件 EXE**：PyInstaller 打包，U 盘即走

## 📑 文档模式：双面 / 续扫 / 合并

扫描参数区有一组「扫描模式」单选：**单面** / **双面（手动）** / **加入现有文档（续扫）**。

### 双面（手动）

1. 来源选「ADF」，整叠纸放进输稿器，扫描模式选「双面（手动）」，点「扫描」扫**正面**。
2. 状态栏提示"正面已扫 N 页"后，把整叠纸**翻面**放回输稿器，再点一次「扫描」扫**背面**。
3. 弹出合并预览确认页序，点「保存并结束」落盘成一个文档。

- 双面是**两趟单面**（用的是自己的合并逻辑，不是扫描仪的双面功能），需要**输稿器（ADF）**把整叠纸翻面重扫 —— **平板没有背面**。
- 背面整叠翻面 ⇒ 背面扫入顺序与正面相反（最后扫到的那张背面正好配正面第 1 页），程序默认**先反转背面再与正面交错**，合并出来的顺序就是 正面1/背面1、正面2/背面2…；若你的放纸方式不需要反转，取消勾选「背面顺序反转」。
- 两边页数不等时，多出来的那几页按原序接在末尾。

### 断点续扫

- 扫描被打断时（例如在倾斜强提醒弹窗里点「中断并从第 N 页重扫」），**前 N-1 页保留**，第 N 页及之后丢弃；把纸从第 N 页重新放好再扫一次，合并后的文档里新页接在保留页后面。当前界面上触发这个动作的入口就是强提醒弹窗里的那个按钮。
- 前提：**设备仍可用**、**已扫的页还在缓存里**。缓存超过 `cache_config.json` 里的过期时间（默认 24 小时）会在启动时被清理 ⇒ 隔天再续扫可能发现页已经没了。
- 「加入现有文档（续扫）」模式扫完一批会暂停，可继续扫下一批；中途退出软件，下次启动会提示"有未完成的文档会话，是否继续？"。会话文件放在 `%APPDATA%\HP_Scan_Tool\sessions\`。

### 大批量合并成一个文档

- 选「加入现有文档（续扫）」一批批扫，点「结束并保存」⇒ 先看合并预览（页序清单 + 缩略图），确认后落盘。
- 输出格式选 PDF ⇒ 合成**一个** PDF；选 jpg/png/tiff ⇒ 每页一个文件，页号跨批次连续。
- 页序规则：**双面** = 正面/背面交错；**续扫（批次）** = 按批次先后顺序拼接、批内保持原序。
- 预计合成内存峰值超过 1.5GB 时会先问"仍要继续吗"，不会静默截断页数。

### 自动纠偏与倾斜强提醒

- 每页写进缓存后自动测一次倾斜角（纯投影法，检测范围 ±8°；小于 0.75° 视为摆正，空白页/墨迹过少不判角度）。
- 连续多页超过阈值（默认 3°、连续 3 页）弹**强提醒**，三个选项：**继续扫描（自动纠偏）** / **中断并从第 N 页重扫** / **强制保存（不纠偏）**。
- 落盘时按阈值施加纠偏（默认 0.5° 以上才重采样）；选「强制保存」的页原样保存、不纠偏。
- ⚠️ 界面里**没有纠偏开关**，上面的阈值只能用配置文件里的默认值。

## 🚀 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 开发模式运行 GUI
python hp_scan_gui_pyside.py

# CLI 模式扫描
python cli.py scan --ip 192.168.1.100 --resolution 300 --format pdf

# 发现扫描仪
python cli.py discover --format json

# 查看扫描历史
python cli.py history --limit 10
```

## 📦 打包

```bash
python build_exe.py
```

输出：`dist/HP_Scan_Tool.exe`（单文件便携版）

## 🗂️ 项目结构

```
hp_scan_gui_pyside.py   # GUI 主程序（PySide6）
escl_engine.py          # eSCL/AirScan 协议引擎
wia_engine.py           # WIA 降级引擎（本地 USB 降级）
wsd_engine.py           # WS-Discovery 引擎（UDP 3702 发现 / 5357 元数据）
listen_engine.py        # 监听模式（等待面板触发）
scan_coordinator.py     # 扫描编排器（业务逻辑层）
save_manager.py         # 落盘（多页 PDF 合成 / A4 归一 / 曝光 / 纠偏施加）
exposure.py             # 曝光后处理（auto / manual）
skew_detect.py          # 倾斜角检测引擎（纯 PIL 投影法；✅ 已接入扫描流水线，随 EXE 交付）
cache_manager.py        # 磁盘缓存管理
history_manager.py      # 扫描历史日志
profile_manager.py      # 按设备保存扫描参数
preset_manager.py       # 曝光 / 扫描预设（内置 4 个 + 用户自定义）
page_meta.py            # 每页元数据（页码 / 尺寸 / 来源 / 纠偏角）
document_session.py     # 文档会话（双面 / 续扫 / 断点续扫的状态与页账本）
doc_merge.py            # 页序合并算法（双面交错 / 批次拼接，纯函数）
config_io.py            # 配置 I/O 共享层（原子写 + 跨进程锁）
cli.py                  # CLI 命令行入口
build_exe.py            # PyInstaller 打包脚本
tools/verify_scan.py    # 真机扫描验证脚本（产出 report.json）
tests/                  # pytest 测试套件
```

## ⚙️ 配置文件

- `scan_config.json` — 用户偏好（分辨率、颜色模式、格式、输出目录、已保存打印机、纠偏阈值）
- `cache_config.json` — 缓存策略（上限、触发线、清理量）
- `history.json` — 扫描历史日志（最多 500 条）
- `profiles.json` — 按设备保存的扫描参数
- `presets.json` — 用户自定义曝光 / 扫描预设
- `sessions/` — 文档会话（双面 / 续扫的页账本，用于中断后恢复）

所有配置文件位于 `%APPDATA%\HP_Scan_Tool\`。
