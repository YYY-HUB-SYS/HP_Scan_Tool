# ADR-0009: 配置文件拆分为职责独立的多个文件

## 状态
已接受 (2026-07-16)

## 决策
将原来的单一 scan_config.json 拆分为：
- `scan_config.json` — 基础设置（主题、分辨率、颜色、格式、来源、已保存打印机）
- `presets.json` — 曝光预设（内置 + 用户自定义）
- `history.json` — 扫描历史（append-only 日志）
- `cache_config.json` — 缓存策略（上限、触发线、清理量）

所有文件位于应用目录（EXE 所在目录或脚本目录），与现有 scan_config.json 同级。

## 理由
- 扫描历史是 append-only 日志，和配置混在一起不合理
- 曝光预设可能有很多条，独立文件方便用户手动编辑/备份/分享
- 缓存策略可能未来需要更复杂的规则，独立文件避免 scan_config 膨胀
- 职责清晰，每个文件有明确的读写模式
