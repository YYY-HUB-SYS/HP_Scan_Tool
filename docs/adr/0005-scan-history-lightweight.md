# ADR-0005: 扫描历史采用轻量级 JSON 日志

## 状态
已接受 (2026-07-16)

## 背景
用户需要找到历史扫描文件。PRD 列为 P3，但实际使用频率不低。

## 决策
轻量级方案：每次扫描完成后记录元数据到本地 JSON 文件（append-only）。
记录字段：时间戳、设备名称/IP、页数、文件路径、扫描参数（分辨率/颜色/格式/来源/曝光模式）。
GUI 提供简单历史列表，点击可打开文件或所在文件夹。

## 理由
- 实现成本极低（一个 JSON 文件 + 一个列表对话框）
- 足够覆盖「找到上次扫的文件」的核心需求
- 不做「重新扫描」功能，避免增加 UI 复杂度和维护成本
- append-only 设计无并发写入风险（单进程桌面应用）
